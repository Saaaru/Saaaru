### 💻 Proyectos y Casos de Uso

> *Nota: Varios proyectos corresponden a software comercial o institucional y se mantienen en repositorios privados.*

#### 1. [SoyKoda](https://soykoda.cloud) — Análisis de Compras Públicas (Chile)
Plataforma web para auditar licitaciones y consultar normativa de compras públicas en Chile.
- **Stack**: Next.js 16, TypeScript, PostgreSQL 16, Google Gemini API, Docker (Dokploy).
- **Funcionalidades técnicas**:
  - Pipeline de agentes para cotejar bases técnicas contra ofertas y generar reportes en `.docx`.
  - Sistema RAG sobre dictámenes de la Contraloría General de la República (CGR) y leyes de compras públicas.
  - Conexión con APIs de Mercado Público y extensión de navegador para captura de datos.

#### 2. Clickera+ — CRM y Operaciones para Agencias
Sistema interno para administración de proyectos, clientes y flujos comerciales.
- **Stack**: Next.js, TypeScript, PostgreSQL, Tailwind CSS.
- **Funcionalidades técnicas**:
  - Control de estados de venta, cobros y asignación de tareas por cliente.
  - Permisos por rol (RBAC) y reportes de estado para equipos.

#### 3. Sistema de Bienestar Municipal (Valdivia)
Plataforma administrativa para gestión de beneficios de funcionarios públicos.
- **Stack**: Next.js, Node.js, PostgreSQL.
- **Funcionalidades técnicas**:
  - Tramitación de solicitudes de beneficios, préstamos internos y convenios.
  - Flujo de aprobación interna y registro de auditoría de trámites.

#### 4. Integraciones Financieras (Chile)
Herramientas para extracción de datos económicos y control de gastos.
- **Proyectos**: `FinanzasChile` y `SubClarity`.
- **Stack**: Python, TypeScript, APIs REST.
- **Funcionalidades técnicas**:
  - Cliente para la API de la CMF (Comisión para el Mercado Financiero) para consulta automatizada de UF e índices.
  - Sistema para seguimiento y cálculo de costos en servicios de suscripción mensual.

#### 5. Automatización, ETL y Flujos de Datos
Proyectos específicos de procesamiento, extracción y utilitarios operativos:
- **Pipeline de Transcripción de Audio**: Segmentación de audio por lotes con Pydub y transcripción/estructuración con la API de Gemini.
- **Database-CGR (ETL Normativo)**: Extracción, normalización y carga de dictámenes de la Contraloría General de la República de Chile para búsqueda técnica.
- **META-Informes**: Orquestador para sincronizar métricas de campañas publicitarias y generación automatizada de reportes.
- **El Carpintero (Gestión de Caja)**: Herramienta de arqueo diario para registro de ingresos, egresos y cuadratura comercial.
